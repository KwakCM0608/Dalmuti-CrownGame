# PC 빠른 대전 / 온라인 모드 표시 규격 통합 체크리스트

PC 온라인 모드는 빠른 대전을 표시 기준으로 사용한다. 네트워크 연결,
방 관리, 초대 코드, 채팅처럼 온라인에서만 필요한 기능은 남길 수 있지만,
게임 테이블 안에서 플레이어가 보는 크기, 위치, 효과와 시간은 같아야 한다.

## 레이아웃과 디자인

| 확인 영역 | 빠른 대전 기준 | 온라인 모드 합격 조건 |
| --- | --- | --- |
| 상단 헤더 | 높이와 게임 영역 시작점 | 연결 상태·초대 코드를 제외한 로고, 규칙 버튼, 테이블 시작점이 같은 축에 놓임 |
| 3열 게임 골격 | 서열 / 필드 / 기록 | 좌우 패널 너비와 가운데 필드의 가용 폭이 같음 |
| 필드 외곽 | 테두리, 모서리, 내부 여백 | 필드 높이, 테두리 굵기, 곡률과 중앙 콘텐츠 위치가 같음 |
| 플레이어 좌석 | 계급 기준 고정 위치 | 좌석 크기, 배경 농도, 테두리, 현재 차례·완주·달무티 강조가 같음 |
| 내 좌석 | 계급 위치에도 내 정보 표시 | 좌석을 비우지 않고 같은 형식으로 표시하되 금색 계열 차별화로 본인임을 구분 |
| 중앙 안내 영역 | `min(560px, 72%)` | 빈 필드, 제출 카드 설명, 계급 선택 안내가 같은 폭과 줄바꿈을 사용 |
| 마지막 제출 카드 | 카드 크기와 겹침 간격 | 장수별 팬 배치와 중앙정렬이 같음 |
| 내 패 도크 | 상태 박스가 패의 중심축을 밀지 않음 | 처음 분배 직후와 카드를 낸 뒤 모두 전체 도크 기준으로 다시 중앙정렬 |
| 내 패 카드 | 빠른 대전 패딩과 겹침 | 패 패딩 `18px 38px 0`, 카드 사이 겹침 `-34px` |
| 행동 영역 | 빠른 대전 하단 박스 | 안내문, 패스, 제출 버튼의 높이·폭·여백이 같음 |
| 모달 배경 | 어두운 와인색 방사형 배경 | 배경 흐림 `12px`, 테두리·그림자·내부 광택이 같음 |
| 막 결과 | 1·2위와 본인 강조 | 행 높이, 색상, 계급 변화, 누적 칩과 결과 표시 시점이 같음 |

## 초반 진행 애니메이션

| 순서 | 공통 규격 |
| --- | --- |
| 계급 정하기 소개 | 문구 크기, 카운트다운, 등장과 퇴장 속도가 같음 |
| 계급 카드 선택 | PC 카드 크기와 간격, 선택 광택, 이미 선택된 카드 상태가 같음 |
| 카드 공개 | 같은 뒤집기 축·지연·전체 지속시간을 사용 |
| 나의 계급 확인 | 카드와 계급명이 겹치지 않고 같은 위치·크기로 표시 |
| 패 공개 안내 | 같은 문구 규격과 `2400ms` 흐름을 사용 |
| 패 뒤집기 | 플레이어별 할당 카드 수만큼 뒷면을 먼저 표시하고 같은 간격으로 공개 |
| 제1막 세금 교환 없음 | 앞뒤 안내와 겹치거나 강제 줄바꿈 없이 이어짐 |
| 세금 교환 | 공개·비공개 정보 범위, 카드 크기, 출발·도착 좌석과 `6000ms` 단계가 같음 |
| 혁명·대혁명 | 안내, 조커 두 장, 붉은 필드와 대혁명 계급 이동 효과가 같음 |
| 게임 시작 | 문구 크기와 출발 플레이어 안내의 리듬이 같음 |

## 게임 중 애니메이션

| 확인 영역 | 공통 규격 |
| --- | --- |
| 카드 제출 | 배우 좌석에서 필드까지 같은 경로, 크기, `2250ms` 잠금과 `2080ms` 이동 |
| PASS | 배우 좌석에서 중앙까지 같은 경로, `1500ms` 잠금과 `1380ms` 이동 |
| 연속 행동 | 앞 행동이 완전히 끝난 뒤 다음 차례의 강조와 타이머 시작 |
| DALMUTI | 배너, 카드, 필드 하이라이트, 자동 PASS 순서·위치·지속시간이 같음 |
| 차례 타이머 | `30000ms`, 남은 `10000ms`부터 같은 긴급 색상 변화 |
| 자동 PASS | 보유 장수가 요구 장수보다 적거나 제한시간 만료 시 같은 표시 흐름 |
| 막 종료 계급 이동 | 별도 대기 없이 이동 시작, `2300ms` 동안 좌석이 튀지 않고 이동 |
| 결과창 연결 | 이동이 끝난 뒤 `280ms` 안정 구간 후 결과창 표시 |
| 대혁명 계급 이동 | 안내 종료 후 별도 선행 공백 없이 모든 좌석이 같은 경로로 이동 |

## 의도적인 온라인 전용 예외

- 연결 상태, 재접속 표시, 방 코드와 방 초기화
- 로비의 준비, 봇 추가와 봇 난이도
- 채팅, 감정표현과 채팅 접기
- 서버 응답을 기다리는 동안의 입력 잠금

이 예외들은 테이블의 좌석 기준점, 내 패 중앙축, 공용 애니메이션 시간,
결과창 표시 시점을 변경해서는 안 된다.

## 회귀 확인 절차

1. 1366×768과 1920×1080에서 빠른 대전과 온라인 모드를 각각 연다.
2. 4명, 5명, 6명, 8명, 10명 게임에서 계급 선택부터 첫 제출까지 비교한다.
3. 온라인에서 내 패가 처음 공개될 때 중앙인지 확인하고, 카드 수가 1장씩
   줄 때마다 다시 중앙에 놓이는지 확인한다.
4. 카드 제출, PASS, DALMUTI, 세금 교환, 혁명과 대혁명의 시작·종료 프레임을
   빠른 대전과 비교한다.
5. 막 종료 시 좌석 이동이 즉시 시작되고, 이동이 끝난 뒤에만 결과창이
   나타나는지 확인한다.
6. 온라인 채팅과 재접속 UI를 열어도 필드와 내 패의 중심축이 움직이지
   않는지 확인한다.

정적 계약은 `tests/desktop-quick-online-parity.test.mjs`에 있다. 설치형
모바일 앱의 규격은 별도의
`tests/mobile-installed-parity.test.mjs`와
`docs/mobile-installed-quick-online-parity.md`에서 관리한다.
