# RL V1 기존 봇 기준전

실행일: 2026-07-31

## 조건

- 인원: 4, 6, 8, 10명
- 각 인원별 300매치
- 매치당 5막
- 난이도별 좌석 수를 동일하게 구성
- 첫 계급은 매치 seed로 무작위 배정
- 이후 계급은 실제 완주 순서로 이동
- 세금, 혁명, 대혁명, 달무티 효과 포함

## 결론

모든 비교 인원에서 `normal`이 `hard`보다 높은 평균 칩과 1위 비율,
낮은 평균 순위와 꼴찌 비율을 기록했다. RL V1 행동 모방의 교사 정책은
`normal`로 고정한다.

이 결과는 현재 `hard` 점수 함수의 전략적 PASS와 위험 회피 가중치가
실제 완주 성과를 악화시킬 가능성을 보여준다. 행동 모방은 기존 최강
기준선을 신경망으로 옮기기 위한 초기화 단계이며, 최종 실력 향상은 이후
PPO와 league self-play에서 수행한다.
