# DCLab 달무티

달무티를 4~10인 빠른 대전으로 연습하거나 초대 코드로 친구들과 함께
플레이할 수 있는 웹 게임입니다.

## 실행

Node.js 22.13 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

- `/`: 4~10인 플레이어 대 AI 빠른 대전
- `/online`: 초대 코드형 온라인 멀티플레이

## 모바일 설치

배포 주소를 Android Chrome에서 열면 초기 화면에 `DALMUTI 설치` 안내가
표시됩니다. 안내가 보이지 않으면 Chrome 메뉴에서 `홈 화면에 추가` 또는
`앱 설치`를 선택할 수 있습니다. PWA는 게임 도중 강제로 업데이트하지
않고 초기 화면에서만 새 버전 적용을 제안합니다.

직접 설치용 Android 테스트 APK는 `artifacts` 폴더에 생성합니다. 이
APK는 개인 기기 테스트용이며, 앱 스토어 공개 배포 전에는 게임명과 카드
그림을 포함한 제3자 권리의 별도 확인이 필요합니다.

## 온라인 게임 구조

- 브라우저는 자신의 패와 공개 정보만 받습니다.
- 셔플, 세금, 카드 제출, 패스, 순위 계산은 서버의 공용 게임 엔진이
  검증합니다.
- 방 상태와 재접속 세션은 Cloudflare D1에 보관됩니다.
- 클라이언트는 짧은 폴링으로 새 상태와 공개/개인 이벤트를 받습니다.

온라인 모드는 4~8개 좌석을 사용하며, 빈 좌석에는 방장이 난이도별 봇을
추가할 수 있습니다. 참가자가 준비하면 방장이 PLAY를 누르고, 서버가
패를 배분한 뒤 각자의 패만 공개됩니다.

## 검증

```bash
pnpm test
pnpm lint
```

테스트에는 덱 분배, 비공개 패, 세금 정보 공개 범위, 중복 명령 방지,
서버 렌더링 검사가 포함됩니다.
